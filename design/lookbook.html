How the three lists are arranged, and the scan→drill flow. The same engine data; switch Mac/iPhone above to see each one adapt.

Layout 1 · Reading Desk (master-detail split)

Lists rail → fund column → wide detail. Best for deliberate desktop reading; on iPhone it collapses to a tap-through stack (list → fund → detail). Like Reeder / Apple Mail.

Layout 2 · Morning Briefing (summary cards → drill)

A deck of glanceable cards per list; tap one to open the full detail sheet. Reflows cleanly from a Mac grid to a single phone column with no structural change. Like Apple Health / Stocks.

Layout 3 · The Nightly (briefing scroll + night scrubber)

A single top-to-bottom “edition” you read once each morning, with a night scrubber and a “what changed since last night” strip up top — leaning into the history + evolution that's native to this engine. Tap a name to expand it in place.
